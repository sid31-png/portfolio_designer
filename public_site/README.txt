AHMED BOUAMAMA — STATIC PORTFOLIO EXPORT

This folder contains the complete portfolio:
- Homepage
- Five project-detail pages
- Images, styles, fonts, and interactive scripts

HOW TO PUBLISH
Upload the entire folder to the root of any static hosting service, such as:
- Netlify Drop
- Cloudflare Pages
- GitHub Pages
- cPanel / traditional web hosting

Keep the folder structure unchanged. The homepage file is index.html.

IMPORTANT
Opening index.html directly from your computer may block JavaScript modules in
some browsers. For a local preview, serve this folder with any simple static
server. Once uploaded to a web host, all routes and interactions will work.
